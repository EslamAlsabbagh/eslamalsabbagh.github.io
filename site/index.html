What I do

Since February 2025 I have been the engineer on a production ERP for HR and employee management, built on Flutter and Supabase and used daily by staff across several departments. It is a real system with real constraints: role-based access that has to hold up under audit, approval chains that route through several levels of management, and a bilingual interface that has to read correctly in both English and Arabic.

Most of my work sits where the data model meets the interface. I design PostgreSQL schemas and enforce access through Row Level Security rather than application code, so that a mistake in the client cannot expose another employee's record. I write backend logic as Deno Edge Functions, including an OAuth 2.0 flow against the Gmail API that sends templated HTML approval mail at each step of a request. On the client side I use BLoC and a clean-architecture split that keeps the data layer swappable — which is what made the interactive demos on this site possible at all.

I take modules end to end, from requirements and fit-gap analysis through workflow modelling to delivery. The parts of the job I find most interesting are the unglamorous ones: migrating a legacy authentication system onto Supabase Auth without disrupting active accounts, or tracing a partial-update defect down to a database trigger that was silently overriding client writes.

Alongside the ERP I have since built two self-hosted systems that run on the client's own servers: a turnstile ticketing and cashier system whose counters keep selling through a network outage, and an Arabic-first task manager and contracts register for a legal team. Both put their business rules in PostgreSQL, so that the rules still hold when the API is called directly.
