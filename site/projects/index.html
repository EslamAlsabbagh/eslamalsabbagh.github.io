HR & Workforce Management Platform

2025 – present · Flutter · Supabase · PostgreSQL · Deno

A 35-screen bilingual ERP covering employee administration, a multi-level approval engine, shift scheduling with swap requests, an organisation structure builder and a statistical dashboard. Access control is enforced end to end through PostgreSQL Row Level Security.

Retail Property Management Platform

In progress · Flutter · Supabase · PostgreSQL

Extends the core ERP with Finance, Legal and RDD modules alongside a standalone tenant-facing Flutter application. Both share one Supabase project and authentication system, with data isolation enforced entirely through Row Level Security. The core schema and RLS helpers are defined; the approval engine connecting leases, fit-outs and contracts is next.

HR Approval & Notification System

Flutter · Supabase Edge Functions · Deno · Gmail API

The multi-level approval and escalation workflow at the heart of the ERP, with automated reminders and templated HTML email at each stage. Escalation paths were modelled and diagrammed ahead of implementation to validate state transitions with stakeholders before any code was written.
